# FutureBattle — 開発仕様書 v0.1

## 1. コンセプト
SF銃撃戦を中心とするFPS×RTS。500〜2,000体規模の戦場で、俯瞰指揮と個別ユニット直接操作を融合する。初期対象はWindows、シングルプレイ。ファストマッチのマルチプレイは拡張目標。

## 2. ゲームモード
- ファストマッチ：1戦完結。初期予算、雇用、拠点収入、補給、増援、勝利条件。将来PvP/PvE・共同指揮。
- キャンペーン：戦争全体の状態、領土、資源、技術、部隊損耗、経験を永続化。
- テストモード：条件固定のAI・バランス・負荷試験。

### キャンペーン開始時の固定選択
- A 戦略シム：国家・全軍を指揮。研究開発・生産・軍制・全軍配置で強化。個体強化は限定。
- B 部隊指揮シム：上級司令部から作戦を受領。師団等の編成・強化・作戦実行。配下ユニットをFPS操作可能。
- C ヒーローシム：個人と少数精鋭部隊を大幅に育成。FPS主体、直属隊員へRTS命令。戦略全体の操作は不可。
- B/C：任務達成・戦功で「発言力」を獲得。ポイント消費で補給・支援・増援・命令変更・特殊装備などを確定取得（使用条件は必要）。信頼度や承認抽選は初期版では採用しない。恒久権限は累積戦功で解放する案。

## 3. 戦闘
- 歩兵、重装歩兵、強化外骨格兵、偵察兵、ドローン、戦闘ロボット、装甲車両、自走砲など。
- 銃撃中心。高低差、射線、遮蔽、側面攻撃、包囲、制圧、士気、兵科連携を重視。物理的優位＋必要最小限の数値補正。
- 偵察→敵情報（位置精度・鮮度）→通信共有→砲撃要請→戦果確認。未発見敵の正確な位置を表示しない。
- 分隊ドクトリン：攻勢／標準／防御。指揮官の行動傾向をパラメータ化。
- 拠点：レーダー、通信、補給、発電、砲兵陣地、高地等。占領効果は機能に直結。
- 増援・予備戦力・損耗のキャンペーン引継ぎ。

## 4. 経済
- 雇用費、生産費、補給費、増援費、拠点収入を基本とする。
- ファストマッチでは維持費を原則省略。キャンペーンでは維持費・研究・修理・兵站を段階導入。
- 価格・戦功ポイント・補正値はすべて仮値。データ駆動で調整可能にする。

## 5. アーキテクチャ
- Unreal Engine 5 + C++ + Blueprint/UMG。Mass Entity/MassGameplayは大規模化時の基盤候補。StateTree、NavMesh、Niagara、Enhanced Input、Unreal Insights。
- 全ユニットに永続UnitID。正規データと表示Actorを分離し、FPS操作権を切り替えてもHP・弾薬・命令等を保持。
- AI階層：戦略AI／作戦AI／分隊AI／個体AI。命令、認識情報、戦闘計算を共通化。
- 描画LODとシミュレーションLODを分離。遠距離戦闘も継続し、プレイヤーに影響する判定は必要な精度を保つ。
- マルチプレイ：サーバー権威型を想定。クライアントへ未発見敵の正確な情報を配信しない。Massのネットワーク同期は別途設計・検証。
- 非参加戦線は簡易戦闘モデルで処理し、結果をキャンペーンに反映。

## 6. 実装順序と完了条件
1. 環境：UE5 C++ Third Personテンプレートをビルド・起動、Git初期コミット。
2. 20体：FPS射撃、AI索敵・射撃、RTS選択・移動命令、ユニット操作切替。
3. 100体：分隊命令、遮蔽・側面、偵察・情報共有、砲撃、拠点占領。
4. ファストマッチ：予算・雇用・増援・勝敗・保存、繰り返しテスト可能。
5. ネットワーク実証：2人・20〜100体で命令・射撃・操作切替をサーバー同期。
6. 500体→2,000体：Mass/LOD/経路・戦闘最適化。Unreal Insightsで計測。
7. キャンペーン：戦略層・AI・A/B/C固定選択・発言力・戦闘結果引継ぎ。
8. PvP/PvE：小規模対戦から段階的に拡張。

## 7. PC環境構築（Windows）
1. Epic Games Launcherから安定版UE5を導入：https://www.unrealengine.com/download
2. Visual Studio 2022（UEの対応バージョンを確認）を導入。「C++によるゲーム開発」、MSVCツールセット、Windows SDK、Unreal Engine関連ツールを選択：https://visualstudio.microsoft.com/downloads/
3. Git for Windows：https://git-scm.com/downloads/win
4. Blender（モデル制作開始時で可）：https://www.blender.org/download/
5. UE5起動→Games→Third Person→C++→Desktop→プロジェクト名 FutureBattle。短い英数字のパスを推奨（例 C:\\Dev\\FutureBattle）。
6. エディタでPlay、Visual StudioからDevelopment Editor/Win64でビルド確認。
7. 必要になった時点でMassEntity、MassGameplay、MassAI、StateTreeなどの互換プラグインを段階的に有効化。
8. Git初期化。Unreal用.gitignoreを使い、Binaries/、Intermediate/、Saved/、DerivedDataCache/を除外。大きなバイナリ素材はGit LFS等を検討。
9. 最初の検証はThird Personテンプレートで行い、FPSカメラとRTSカメラを追加する。

## 9. 開発ルール
- 最初から2,000体を目標にした巨大な一括実装はしない。
- 仕様・データ・テストをバージョン管理し、動作する段階を残す。
- AI生成コードはエディタ実機でビルド・実行・性能検証する。
- エンジン更新前にバックアップとプラグイン互換性確認を行う。
