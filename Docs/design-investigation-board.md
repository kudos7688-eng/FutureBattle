## 困っていたこと

- 並行するセッション（作業ツリーごと）が、同じ問いを互いに知らずに調べていた。例：近い戦いが起きない原因（武器と高級小隊 11-22 12:45 と 個人AI 13:35）、西と東の偏り（区画AI が5回、群制御が前線の向き・命令の順で）。

## 仕組み

`Setup/Board.py`（Python 3。`python -I Setup/Board.py ...`）。置き場所は計測ロックと同じく作業ツリーの外 `C:\Users\nanek\Documents\FPS\.lock\`。どのブランチからも、書いた瞬間に見える。

| 呼び方 | いつ | 働き |
|---|---|---|
| `find <語> [<語>...]` | 調べ始める前に必ず1回 | 進行中の調査と、過去にわかったことの中から一致するものを出す |
| `claim --who <系統名> --topic "<問い>" --keys <切替名,ファイル名,関数名,日本語2〜4語> [--question ...] [--hours 4]` | 30分以上かかりそうな調査・原因究明を始めるとき | 登録する。重なる調査があれば表示して終了コード2 |
| `note --who <系統名> --fact "<わかったこと1行>" --ref "<STATUS の項目・ログ>"` | 原因・行き止まり・効いた/効かなかった数値がわかったとき | 記録する（`board-findings.jsonl`、追記のみ） |
| `done --who <系統名> --result "<結論1行>" --ref ...` ／ `drop --who <系統名>` | 調査を終えた・やめたとき | 閉じる。結論は記録に残る |
| `status` | 作業の区切り | 進行中の調査の一覧（期限切れに印） |

- 一致は、キーと問いの語の部分一致（大文字・小文字を区別しない）。**キーが要**：試験切替の名前（`BattleArmsCharge`）、ファイル名（`BattleArea.cpp`）、関数名、日本語の短い語（`近い戦い`、`西東の偏り`）を付ける。
- 重なりが出たら、相手の記録を読み、まだ足りなければ相手のセッションに `SendMessage` で聞いてから進める。目印であって強制ではない（同じことを別の角度で調べる判断は各セッションに任せる。そのときは claim の `--question` に違いを書く）。
- 文章が `-` で始まる（試験切替の名前から書く）ときは `--fact=-Battle...` の形にする。
- STATUS への記録はこれまでどおり（掲示板は STATUS の代わりではない）。掲示板の `note` は1行で、詳しくは `--ref` の先に書く。
