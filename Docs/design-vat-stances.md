# 遠景（VAT）の兵もしゃがむ・伏せる（ROADMAP「随時」表示の設計）

2026-11-22 1時25分 Claude（ロードマップに従う改善活動）。**設計のみ。未実装。** 出どころは ROADMAP 11-20「随時」の表示「遠くのVAT表示の兵がしゃがまない」。表示のみで、判定（姿勢による当たりや見え方）は今のまま。

## 1. 今

- 遠くの部下は VAT（頂点アニメーションのテクスチャ）で描く。焼いてあるクリップは3本だけ：構えて立つ（`MF_Rifle_Idle_ADS`）、歩く（`MF_Rifle_Walk_Fwd`）、装填（`MM_Rifle_Reload`）。`BattleVATBake.cpp` の `BakeBattleVAT`、姿勢の番号は 0／1／2。
- 近くの部下は全身のクリップで、しゃがみ・伏せ・遮蔽のクリップ（`FollowerClip`、BattleStance.cpp）を使う。遠景に替わると立った姿に戻る。
- 死亡は 11-21 に「死んだら遠景から外して近くの体で死亡クリップ」にしたので、遠景の死亡は解決済み。

## 2. 変えるところ

1. **焼くクリップを足す**：しゃがんで構える、しゃがんで歩く、伏せて構える（手持ちのクリップから選ぶ。近くの部下が `FollowerClip` で使っているものと同じにして、遠近の切り替えで姿が跳ばないようにする）。走り（今は歩きで代用）も足すかは、テクスチャの大きさを見て決める。
2. **姿勢の番号を広げる**：遠景の番号＝「動き（構え／歩き／装填）」×「姿勢（立・屈・伏）」。`ABattleVATDisplay::ChangePose` に姿勢も渡す（`UBattleLeaderRuntime::StanceOf`）。伏せの装填は伏せて構えるで代用。
3. **焼き直し**：今の焼き出しは上書きを拒むので、新しいフォルダに焼いて、データ資産の参照を切り替える（`-BattleVATSet=2` で新しい方、既定は確認の後に切り替え）。焼き出しの記録（出典・サンプル数・量子化の誤差）は今と同じく `Provenance` に残す。
4. **大きさ**：今は3本ぶんの行。6本で約2倍（60Hz・RGBA16F）。読み込みとメモリを `Test-VATDisplay.ps1` で確かめる。

## 3. 確かめ方

- `Test-VATDisplay.ps1` に「しゃがんだ遠景の兵の頭の高さが、近景のしゃがみと10cm以内」の段を足す。
- 試合が変わらないこと：`-BattleStateTrace`（`Docs/design-divergence-trace.md`）で、新旧の VAT の試合が「状態一致」になること。**表示の変更で試合が変わる問題（段階2）が片付く前に入れると、また原因の分からないずれが増えるので、段階2の後に入れる。**
- 画面：描画ありで遠景のしゃがみ・伏せを撮影し、ユーザーに見てもらう。
