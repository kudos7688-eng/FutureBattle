## このゲームの今の動き（コードで確かめた分）

- **再生の仕組み**：隊長（操作できる兵）は `PlayAnimation` で1本のクリップを丸ごと流す（`BattleUnit.cpp` の `UpdateWeaponPose`）。上半身と下半身を分けたり、2本を混ぜたりする仕組みはない。遠くの部下は、焼き込んだ頂点アニメ（VAT）で表示し、クリップの種類は「待機・歩き・装填」の3つ。
- **使っているクリップ**：小銃の待機（構え）・前歩き・装填、しゃがみの待機・前歩き（Lyra から取り込み済み）。合わせて5本。
- **クリップがないもの**：伏せ（体を縦に縮めた仮の表示）、死亡（体を倒して回すだけ。Lyra の死亡6本は取り込み済みだが、どこからも使っていない）、被弾（取り込み済み・未使用）、乗り越え（体を移すだけ）、横歩き・後ろ歩き（前歩きを流すだけ）、射撃の反動、手榴弾、遮蔽の姿勢、しゃがみの出入り（取り込み済み・未使用）。

**結論**：骨が同じ TPS（`UE5_Anims`）と Lyra はすぐに使える。GASP は骨が違い、武器を持たないので、使う場面は限られる。いちばん大きな制約はアセットではなく、**ゲーム側が「1本のクリップを丸ごと流す」作りであること**。上半身と下半身を分ける、反動を重ねる、照準に合わせて上下させる、をするには、隊長用の C++ のアニメ処理（または AnimBP）を足す必要がある。

**勧める順番**：(1) ブラインドファイアと遮蔽の姿勢（今回）→ (2) 死亡（取り込み済みの6本を呼ぶ）→ (3) 伏せ（TPS）→ (4) しゃがみ・伏せの移り変わり → (5) 移動の向き別クリップ → (6) 隊長用のアニメ処理（上半身の重ね）→ 反動・被弾・照準の上下。

## 今回の実装：ブラインドファイア（ワークツリー `FutureBattle-blindfire`、ブランチ `blindfire`）

- **操作**：遮蔽で隠れている間に、**構えずに射撃**するとブラインドファイア、**構えて射撃**（右クリック長押し＋左クリック、パッドは LT＋RT）すると今までどおり身を出す。
- **弾の出る位置**：低い遮蔽なら壁の上（地面から175cm、だめなら200cm）、横にずれて撃つ遮蔽なら縁の外側（しゃがんだ胸の高さ、横に45〜150cm）。頭からその位置までと、そこから狙う向きへ1.5mが壁に当たらないことを確かめる。どこもだめなら今までどおり身を出す。
- **体**：その場でしゃがんだまま。見つかり方と当たり方は変わらない。
- **散らばり**：姿勢と構えの効果を使わず、基準の4倍（`-BattleBlindFireSpread=`）。
- **AI**：試験用の切り替え `-BattleAIBlindFire=1`（既定0）。制圧されて隠れている間、最後に見た位置へ撃つ。
- **切り替え**：`-BattleBlindFire=0` で今までの動き（射撃で必ず身を出す）。
- **アニメ**：TPS の遮蔽アニメ23本を `/Game/Characters/Mannequins/Anims/Rifle/Cover/` に取り込み（`-run=BattleVATBake -ImportCoverAnims`）、ブラインドファイアの間（撃ってから0.6秒）だけ流す。既定は上から撃つときが `AS_CoverLo_AimU_down`、横から撃つときが `AS_CoverLo_AimR`。取り込みのときに各クリップの頭・手の高さと銃の向きを計測して、選び直す（`-BattleBlindFireClipTop=`／`-BattleBlindFireClipSide=` でビルドなしに差し替えられる）。
- **試験**：`Test-CoverActions` に「構えずに撃つとブラインドファイアになり、体は陰に残る」「構えて撃つと身を出す」を足した。
