# 40部隊を扱う部隊一覧と、選んだ部隊の詳細（ROADMAP「随時」操作・UI の設計）

2026-11-22 1時05分 Claude（ロードマップに従う改善活動）。**設計のみ。未実装。** 出どころは ROADMAP 11-20「随時」の操作・UI（部隊一覧の絞り込み・並べ替え〔40隊で使えるか〕、選択部隊の詳細、購入ボタンに得点の減り）と 11-15「指揮UIの設計」。小隊の上限は30（11-20 ユーザー決定）、40 は段階6で決める。表示のみで、試合は変えない（段階2の記録 `-BattleStateTrace` で確かめてから入れる）。

## 1. 今の部隊一覧（11-22、`ABattleHUD::DrawSquadList`）

- 右側。行の高さ56ピクセル（3行：名前と状態／命令・距離／理由）。1080p で見える行は約15。
- 上部に軍のタブ（前線軍／攻撃軍／未所属／全部）と並べ替え（番号順／損耗順／拠点別）。群の見出し行、ドラッグで軍・群へ入れる。
- 無いもの：状態での絞り込み（交戦中・補給中・待機・停止）、1行の詰めた表示、選んだ部隊の中身（兵ごとの体力・弾・姿勢・遮蔽・制圧、判断の経過）。

**30〜40部隊では、3行の行を15ずつスクロールして探すことになり、「どこで何が起きているか」が一覧で読めない。**

## 2. 変えるところ

### 2.1 詰めた表示（1行）と切替
- 行の高さ24ピクセルの1行表示を足す：`[兵種の記号] 第12小隊  ■■■■■□□□ 5/8  交戦 120m  ⚠弾`。兵種の記号は作戦画面の兵種アイコン（11-21）と同じ形を小さく。
- 一覧の上の並べ替えの隣に「詳しく／詰める」の切替。30部隊を超えたら詰めた表示を既定にする（切替は覚えておく）。
- 詰めた表示の行にポインタを重ねると、その行だけ今の3行表示で浮かせて見せる。

### 2.2 状態の絞り込み
- 軍のタブの下に小さな切替を4つ（複数選べる）：`交戦中`（直近10秒に撃った・撃たれた）、`補給・再編`（補給へ戻る・再編中）、`待機`（命令を待つ・到着して止まっている）、`要注意`（下の問題の印が1つ以上）。
- 何も選ばないときは全部。軍のタブと掛け合わせる（「攻撃軍の交戦中」など）。

### 2.3 問題の印
- 行の右端に、問題があるときだけ印を出す：`弾`（主武器の弾が2割未満の兵が半数以上）、`長`（隊長が負傷・体力半分未満）、`詰`（通行待ち・移動の詰まりが5秒以上）、`釘`（押さえ込まれている）、`遠`（目的地まで500m以上で止まっている）。いまの `FBattleSquadSummary::ProblemFlags` を使い、足りない種類を足す。
- 印の付いた部隊の数を、一覧の見出しに `要注意 3` として出す（押すと絞り込みの `要注意` が入る）。

### 2.4 選んだ部隊の詳細（新しいパネル）
- 部隊を1つだけ選んでいるとき、一覧の下（ミニマップと重ならない位置）に出す。2つ以上選んでいるときは「選択中 n部隊：兵 合計 a/b、弾の少ない兵 c」の要約だけ。
- 中身：
  | 段 | 内容 |
  |---|---|
  | 見出し | 名前、兵種、委任／手動、所属の軍・群、命令と目的地までの距離 |
  | 兵 | 兵ごとに1行：役（隊長・支援火器など）、体力の棒、弾（今の弾倉／予備）、姿勢（立・屈・伏）、遮蔽（なし・接近中・隠れ・覗き・ブラインド）、制圧の棒 |
  | 判断の経過 | 直近5回の判断の理由と時刻（例：`12秒前 被弾→遮蔽へ`、`40秒前 区画 F7 を制圧`）。表示側で理由の変化を見張って覚える（試合の状態には書かない） |
  | ボタン | `補給へ戻す`・`後退`・`群から外す`（既存の命令を呼ぶだけ） |
- 兵の行を押すと、その兵へカメラを寄せる（直接操作には入らない）。

### 2.5 購入ボタンに得点の減り（11-15 の案の残り）
- 購入ボタンに「買うと終了時の得点 −4（費用12、生存8人ぶん +8）」のように出す。今の得点の規則（11-22 ユーザー決定で今のまま）から計算するだけ。

## 3. 確かめ方
- 自動試験：`Test-LeaderCommand` に「詰めた表示への切替」「状態の絞り込み」「詳細パネルのボタンが命令を出す」の段を足す（クリックの位置はレイアウトの構造体から計算する。今の一覧の試験と同じやり方）。
- 画面：マップI で30部隊（上限30）の状態を描画ありで撮影。読みやすさ・操作感はユーザーのテストプレイ。
- 試合が変わらないこと：`-BattleStateTrace` の記録で、表示を出す前後の試合が「状態一致」になること。

## 4. 実装の順
1. 詰めた表示と切替（`FBattleSquadListLayout` に行の高さの切替を足す）。
2. 問題の印と見出しの `要注意 n`。
3. 状態の絞り込み。
4. 選んだ部隊の詳細パネル（判断の経過は HUD 側で覚える）。
5. 購入ボタンの得点の減り。

操作は群制御・射程円の担当が触っている所（部隊一覧のタブ・ドラッグ）と重なるので、実装の前に担当へ声をかける。
