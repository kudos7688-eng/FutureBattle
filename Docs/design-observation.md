# 観測に基づく戦術判断（-BattleObservedTactics）

2026-11-21実装、実行未検証。`-BattleObservedTactics=1` は両陣営共通、既定0。`BattleTactics::ObservedTactics()` は `ObservedArmour()` の隣でFParseの結果を一度だけ保存する。他の切替は強制しない。

- **O04**：`AreaIntelView` の本拠地認識を、通常視界の範囲内にいる自軍兵の `AreaVisible` 成功、または配信済み偵察報告の `bHomeObserved` に限定する。既存のHomeObserver選択・1秒キャッシュを共用し、本拠地Actorの位置へ視野角・遮蔽検査を行う。長距離偵察は報告完成時に本拠地への実視認を測定し、報告の記憶期限までその結果を使う。配信後に偵察兵の向き・位置から再判定しない。ArtilleryObserved併用時の発射直前再検査も同じActor位置に揃える。本拠地一点の視認は周囲すべての敵不在を保証しない。既存報告は敵接触がある場合に進むため、敵がいない本拠地だけの長距離報告は新設しない。
- **O05**：群の押している判定では `CapturingTeam` の代わりに `ObservedOwner` を使う。最近見た時刻と自軍の到着条件は維持し、既知の局所戦力優勢による判定も残す。占領進行中を推定する新しい保存項目は追加しない。ON時の既存 `BATTLE_GROUP_PUSH` の `capturing` 値は観測所有者を表す。
- **O07**：Thinkの目標選択・再捕捉時に、採用した接触の位置を同時に保持する。装甲AIが区画判断前に再選択する場合も、採用した接触の位置を返す。区画外判定・遮蔽・PinnedAt・CloseInAt・到着方向はこれを使い、先頭の別接触から引き直さない。陣営全体の重複接触集約順の変更は今回の依頼範囲外。
- **O08**：旧Actor・MixedDriverの停止と目標採用は可視接触に基づけ、実体が消えていても観測が更新されるまで判断を保持する。即時射線検査は最終射撃条件に残す。旧分隊・MixedSquadAIの援護判定も可視接触を使い、現在射線で否定しない。通常Followは従来から分隊目標で停止しているため、その条件は維持し、外部へ示すEngaging状態を射線成功から観測条件へ分離する。実際に発射した記録・自軍の弾薬・再装填・速度は従来どおり。
- **O09**：通常Followの分離とStableMoveの迂回候補に、近傍の味方実位置と移動兵自身の直接可視接触だけで作った局所格子を使う。敵は共有接触・非可視記憶を除き、LastKnownPositionで格子へ入れる。敵の実位置格子・現在速度・生死によって候補を作らず、見えない所で死亡しても最後の可視接触が残る間は候補が残る。継続中のPassingIDの解除・二点目更新も同じ観測位置を使用する。味方の速度・経路・生存と物理Sweep・壁検査・衝突解決は維持する。分隊接触の追加集約や新しいLOS走査は行わない。
- **O11**：接触生成時に、長距離視界による通常SightRange外の測定かどうかと、通常共有の可否を記録する。`IsScoutLongContact` は現在の観測者・受信者の位置やHasLongSightを再照会せず、接触の取得時フラグを読む。通常共有も取得時フラグを使い、長距離の1.0〜1.1倍境界帯は偵察報告待ちに統一する。長距離偵察以外の共有距離上限1.1倍は取得時点で保持する。報告コピーはこの出所を維持する。送受信者の生存・通信距離・遅延の通信ルールは変更しない。

OFFでは従来の距離判定・現在占領状態・先頭接触・即時射線による採否・実位置格子と速度・現在の偵察状態による判定を選ぶ。追加のLOS測定、観測格子作成、接触の配信属性更新はON時のみ。候補の旧列挙順と短絡評価を維持し、乱数呼び出しとゲームログは追加しない。依頼された既定OFFスモーク確認1件だけを既存確認の隣に追加する。OFFの実行結果一致は未確認。

接触の配信属性は非UPROPERTYの一時値で、C++の接触・報告コピーでは維持し、ディスク保存形式は変更しない。ディスク復元時の出所不明は保守的に長距離扱い・通常共有不可とし、新しい視認で更新する。偵察報告の本拠地フラグも既存の一時報告と同じ寿命。ONでの保存往復の完全一致は保証しない。

追加負荷はAreaIntelの最大毎秒の本拠地LOS、偵察報告完成時の本拠地LOS、移動兵の近傍味方格子と自己接触の走査・局所格子構築。回避評価上限32件、既存の移動Sweepと経路探索予算は維持する。負荷・狭路の詰まり・接触失効境界は未計測。
