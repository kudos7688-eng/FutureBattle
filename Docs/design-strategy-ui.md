# 戦略層を画面に出す・プレイヤーが方針を指示する（戦略層の段階5「作戦画面の表示」の詳細設計）

2026-11-22 1時 Claude（ロードマップに従う改善活動）。**設計のみ。未実装。** 戦略層の本体は `Docs/design-strategy-layer.md`（ブランチ `strategy` に S1〜S4 を実装、未ビルド）。この文書は、その状態をプレイヤーに見せる表示と、プレイヤーが委任した部隊に方針を指示する操作を決める。表示の文言は日本語（ユーザー決定）。

## 1. 原則

- 出すのは**自軍の**方針と、自軍が観測した情報だけ。敵の方針・敵の状況図は出さない（既存の原則）。
- 戦略層はプレイヤーの軍では**委任した部隊にだけ**働く（`bPlayerDelegated`）。委任していない部隊が1隊も無い（全部手動）ときは、方針の表示を「手動指揮中」とだけ出す。
- 表示は戦略層が持つ値（`FBattleAreaState::Strategy*` と、見直しのときに作った状況図の写し）を読むだけにする。表示のために状況図を作り直したり、視線判定をしたりしない。
- 段階2（`Docs/design-divergence-trace.md`）が片付くまでは、表示が試合を変えないかを `-BattleStateTrace` で確かめてから入れる。

## 2. 表示

### 2.1 方針の帯（作戦画面の上部の帯の右）
- `AIの方針：展開中（集中先はあと1分20秒で決める）`
- `AIの方針：集中 → 拠点C（あと45秒は変えない）`
- `AIの方針：集中 → 拠点C ／ 保持：拠点A`
- プレイヤーが指示しているとき：`方針：集中 → 拠点C（指示）`
- 押すと（クリック・パッドの決定）、カメラが集中先へ移る。

### 2.2 戦線の状態（作戦画面とミニマップ）
- 拠点ごとに、状況図の状態を拠点の輪の外側の細い輪で出す：不明＝灰の点線、敵優勢＝赤、拮抗＝黄、自軍優勢＝緑。輪の下に「敵 約7（12秒前）」（知っている敵の数を四捨五入、最後に見た時刻）。
- 集中先には太い矢印（自軍の前線の中心 → 集中先）、保持の拠点には盾の印。
- 表示の量を抑えるため、L キー（射程の円）と同じく、表示の切替を1つ足す（例：`;` キー「戦線の状態：出す／集中先だけ／出さない」）。キーは実装のときに既存の割り当て（Q J K T G H E Tab P L M N Z F V 0〜9 − . F5〜F9 など）と重ならないものを選ぶ。

### 2.3 通知
- 方針が変わったとき：`方針の変更：集中 拠点B → 拠点C（拠点Bを確保）`。理由は `BATTLE_STRATEGY` の reason（open／taken／review／counter）を日本語にしたもの（展開の終わり／確保／見直し／反撃）。
- 保持を始めた・解いた：`拠点Aを保持（敵が優勢）`、`拠点Aの保持を解除 → 拠点Dへ反撃を検討`。

## 3. プレイヤーの指示

| 操作 | 働き |
|---|---|
| 拠点（または区画）を選んで「集中先にする」（区画のパネルのボタン。キーは実装時に決める） | 自軍の戦略層の集中先をその拠点に固定する。AI の見直しでは変えない。拠点を取ったら AI の選び方に戻る（「取ったら次も指示を待つ」にするかはテストプレイで決める） |
| 「保持する」 | その自軍の拠点を保持の戦線にする（S3 の保持と同じ扱い。AI が解くことはしない） |
| 「AIに任せる」 | 指示を消す |

- 保存：プレイヤーの指示は `FBattleAreaState` に `StrategyPlayerFocus`・`StrategyPlayerHolds` として足す（保存・読み込みで残る）。
- 戦略層の `UpdateStrategy` では、チーム0にプレイヤーの集中先があればそれを Best にして見直しを飛ばす（点数は記録のためだけに計算する）。

## 4. 確かめ方

- 自動試験：`Test-LeaderCommand` に「集中先にする → 戦略層の集中先が変わる → 委任した攻撃群の目標が変わる」と「保存して読んでも指示が残る」の段を足す。
- 画面：マップI で描画ありの撮影（帯・輪・矢印・通知）。操作感はユーザーのテストプレイ。

## 5. 実装の順

1. 戦略層の見直しのとき、状況図の写しを `UBattleMatch` に陣営ごとに残す（表示用。判断には使わない）。
2. 方針の帯と通知（文字だけ）。
3. 戦線の状態の輪と集中先の矢印（作戦画面・ミニマップ）と、表示の切替キー。
4. プレイヤーの指示（パネルのボタン）と保存。

前提：戦略層 S2 の片側試験の結果を見て、戦略層を残すと決まってから。
