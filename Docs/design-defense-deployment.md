# 守りの配置と、激しい区画への計算の集中（設計、2026-11-25、未実装）

ユーザーとの相談（11-25 9時〜）で決めた仕様。数値は仮。

## きっかけ

- 武器機能の片側試験で、普通の小銃小隊の躍進は、どの条件でも損になった。損になったのは、知らされた敵へ走る場合も、見えている敵へ走る場合も、守る小隊の20m以内の躍進も同じだった（`design-infantry-arms.md` の「片側試験」「迎え撃ち」）。
- 守る側は「敵へ近づく」のではなく、小隊として兵を散らして置き、敵が片側へ躍進してきたら反対側が撃てるようにするべき（ユーザー）。
- TPS で見たときに没入感があるよう、守りは機能する仕組みにする。全体（前線）は簡単に計算し、躍進や攻防の激しいところに計算資源を集める（ユーザー）。

## 段階1：守りの配置（散らして置く）

- 守る任務の小隊が対象。攻める小隊の躍進は変えない。
- 小隊長が「敵の来る向き」を決める。材料は、観測した敵の位置と、区画の前線の向き。
- 兵を2〜3組（左・中・右）に分け、来る向きと直角の線の上に、組どうし10〜15m離して遮蔽に置く。
- 場所の良さは、敵が躍進してきそうな遮蔽を斜めから見られる数で測る。敵が躍進してきそうな遮蔽とは、敵とこちらのあいだにあり、正面からは敵を隠すが横からは隠さないもの。
- 一度置いたら動かない。来る向きが45°以上変わったときだけ置き直す。
- **遮蔽が少ない場所では、散らして置けない。それを補う仕組みは入れない。** 守りが弱い場所は弱いままにして、地形による有利・不利（戦略性）にする（ユーザー）。

## 段階2（後で）：躍進に対して横から撃つ

- 敵の躍進に気づいたら（走り込みの見張りの仕組み）、小隊の中で知らせ合う。
- 近づかれた側の組は、遮蔽にとどまって身を低くする。反対側の組は、躍進の行き先を横から撃つ。
- 攻める側の援護射撃（`-BattleArmsCoverFire`）の、守る側の版。
- ユーザーは、ほかの仕組み（区画の割り当て・陣形）とぶつかることを懸念している。作る前に、どの兵を誰が動かすかを決める。

## 計算を集める区画の選び方

単位は区画（H・I・J・K）。区画の無いマップ（A〜E）では、詳しい計算をしない。詳しく計算する区画では、段階1の配置の評価を2秒おきに行い、段階2をする。簡単な区画では、決めた配置を保ち、評価は10秒おきにする。1人ずつの遮蔽探しは、どちらの区画でも今までどおり。

上から順に優先する。

1. **プレイヤーの周り**：必ず詳しく計算し、上限の数には入れない。
   - プレイヤーの位置から半径40mの円にかかる区画を、すべて詳しく計算する（区画の角では最大4区画）。区画の境で戦っていても、両側が詳しくなる。
   - プレイヤーが離れても、10秒は詳しいまま続ける。
2. **攻撃指示の区画**：群の仕組みと結び付ける。上限は両軍あわせて6区画。
   - 攻撃の群（`FBattleGroup` の種類0の突入群、種類2の奇襲群）が前進の段階にあるとき、次の2つの区画を詳しく計算する。
     - 目標の拠点がある区画
     - 集合地点から目標へ向かう道の、最後の1区画
   - 詳しくなるのは、**攻める側の小隊だけ**。
   - **守る側の小隊は、守る側自身が観測してから詳しくする**（11-25 ユーザー決定）。観測とは、その区画で敵を見た、または撃たれたこと。攻める側の指示で守る側を詳しくすると、「攻められる区画の守りだけが賢くなる」ので避ける。
   - 群が保持の段階に入ったら、3の点数で残すかを決める。群が退いたら外す。
3. **前線の接触**：前線の区画を点数で選ぶ。上限は2区画。
   - 点数（直近10秒）：躍進・走り込みが見られた（1回3点）、弾が当たった（1発1点）、50m以内の射撃（1発0.2点）、兵が倒れた（1人2点）。どれも、実際に起きて誰かが観測した出来事。点数は計算の割り当てにだけ使い、AI の判断材料には渡さない。
   - 5点以上で入る。2点未満が10秒続いたら出る。枠が埋まっていれば、最低の区画の1.5倍以上の点数で入れ替える。入ってから10秒は追い出さない。
   - 点数で選ぶ区画でも、守る側は観測してから詳しくする（2と同じ）。

- **時間の上限**：詳しい計算の時間を1フレームごとに測る。平均が仮に1.0msを超えたら、1→2→3の順を守ったまま、3から区画を順に回して処理を減らす。
- 詳しい区画から外れても、兵の動きが急に変わらないよう、決めた配置はそのまま保つ。考え直す間隔だけを長くする。
- 記録すること：
  - 詳しい区画の数の推移（1・2・3の別に）
  - 区画の出入りと入れ替えの回数
  - 詳しい計算の時間
  - 守る側が詳しくなるまでの遅れ（攻撃指示から観測まで）

## 確かめ方

- 試験切替（既定0）で作り、片側試験（`-BattleArmsTeam` と同じ考え方の、片方の軍だけに効かせる切替）で、切替なしの結果と比べる。比べるもの：得点、与えた損害、撃破、損失、守る小隊の撃った数と隠れていた割合。
- マップH・I・J（区画のあるマップ）で行う。
- 性能は、60FPSの負荷試験で、詳しい計算の時間と1フレームの時間を見る。

## 決まっていないこと

- 段階2で、どの兵を誰が動かすか（区画の割り当て・陣形とぶつからない決め方）。
- 数値（組の数、間隔、上限、点数の重み、時間の上限）。
- 実装の順番。案：計算を集める区画の選び方と記録 → 段階1 → 段階2。
