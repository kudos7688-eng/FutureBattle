# 勝敗・得点・経済の見直し（ROADMAP 段階6の設計案）

2026-11-22 0時50分 Claude（ロードマップに従う改善活動）。**設計案のみ。未実装。得点の数え方・規則の変更はユーザーの決定が要る**（ROADMAP 11-17「得点の数え方は、ほかの仕組みが進んでから見直す」、AGENTS の採否の決め方）。ここでは判断の材料として、今の規則の問題と選択肢、確かめ方を並べる。

## 1. 今の規則（11-22）

- 敵本拠地の破壊で即勝利。破壊がなければ時間切れ（A〜D 600秒、E〜I 900秒）で **得点＝所持資源＋生存兵数＋保有拠点×20×拠点の価値**（外骨格兵は1人で5人ぶん）。`UBattleMatch::AreaScore`。
- 収入：20秒ごとに 基本4＋保有拠点1つにつき4（INC4、11-16 ユーザー採用）。開始資源は `AreaStartCredits`。
- 購入：小銃小隊8人・費用12（11-19）。補充は1人1。稼働小隊の上限30（11-20）。
- 試験切替として「戦果点」（`-BattleAreaWarScore`、11-14 実装）がある：拠点1つにつき5秒ごとに1点＋敵に与えた損失1人につき1点＋終了時の残り資源。相手の点は観測からの推定で表示。

## 2. 分かっている問題

| 問題 | 根拠 | 何をゆがめるか |
|---|---|---|
| よく戦うほど得点が下がる：兵を失うと生存数が減り、補充・購入で資源も減る | STATUS 11-18（群の評価の項）「得点の数え方は群や兵種の評価をゆがめる」 | 攻める作戦・群・高価な兵種が、勝敗の上で過小評価される。片側試験の結論がこの規則に引きずられる |
| 少人数の兵種が不利：生存「人数」で数える | ROADMAP 11-17 | 戦車（1両）・偵察組（2人）を持つと得点が減る。外骨格兵だけ5人ぶんの例外がある |
| 資源をためると得点になる：購入は得点を12減らし、8人を足す（差し引き −4） | ROADMAP 11-16 の前提 | 終盤に買わないのが得。中盤以降は収入不足で、失った兵の約3割しか補充できていない（11-16） |
| 拠点の得点が終了時の保有だけ | `AreaScore` | 最後の数十秒の取り合いで決まる。途中で長く持っていた価値が残らない |

## 3. 選択肢

### A. 今の式のまま、例外を増やす（最小の変更）
- 少人数の兵種の「人数」を、費用に比例した人数ぶんで数える（例：戦車 費用40＝小銃小隊の約3.3倍 → 26人ぶん）。外骨格兵の例外を一般化する形。
- 良い点：小さい変更で、今までの比較と連続する。 悪い点：「よく戦うほど下がる」は残る。

### B. 戦果点に切り替える（11-14 に作った試験切替を既定にする）
- 拠点の保持時間＋与えた損失＋残り資源。得点は戦った量と保持した時間で増える。
- 良い点：攻める・戦うことが得点に出る。11-14 のユーザーの方向（相手の意図が途中まで分からない、浸透と予備）に合わせて作ってある。 悪い点：今までの片側試験（11-15〜11-21 の採否）との比較が切れる。数値（5秒1点、損失1点）は未検証。

### C. A と B の中間：今の式＋拠点の保持時間
- 得点＝所持資源＋生存兵数（費用で重み付け）＋**拠点の保持時間（例：60秒保持で1点）**＋終了時の保有×10。
- 良い点：今の式の延長で、途中の保持が残る。 悪い点：B ほど「戦うこと」は評価しない。

**Claude の提案**：まず **B と今の式の両方で採点だけする**（試合は同じ、終了時の点の計算を2通り出す）。11-15 以降に既定にした変更（S4＋S6、部隊群、前線軍、遮蔽優先など）を B の点でも勝っているか見直し、結論が入れ替わるものがあるかを数える。入れ替わりが多ければ規則が評価をゆがめている証拠になり、ユーザーが B（または C）を選ぶ材料になる。

## 4. 確かめ方（試合の結果は変えない作業から）

1. 採点だけの記録：`metrics.json` に、今の得点に加えて B（戦果点）と C の点を常に出す（戦果点の計算 `WarScore` は既にあり、`-BattleAreaWarScore` を付けなくても裏で数えられるようにする。試合は変わらないので `Compare-MatchResults` の比較項目からは外す）。
2. 既存の評価試合の読み直し：凍結ビルドで、主な既定化の判断（S4＋S6、`-BattleAreaGroups`、`-BattleFrontLine`、`-BattleCoverPriority`）を片側試験で回し直し、3通りの点で勝ち負けを並べる。
3. 経済：戦略層の段階 S4（購入を局面に従わせる）の後に、予備資源の目標と収入（INC4 のまま／終盤に減らす）を片側試験で比べる。小隊の上限（30／40）はこのとき決める（40 は負荷が約1.5倍、11-20）。
