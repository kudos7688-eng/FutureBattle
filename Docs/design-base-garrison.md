# 基地と守備隊（設計メモ、2026-11-25）

本拠地を「小銃で数十秒で壊れる箱」から「守備隊の居る基地」に変える案。ユーザーの提案と決定（11-25 17時ごろ）をまとめる。実装は段階1だけ着手済み。

## 1. きっかけ

マップK で壁の止まりを直す（`-BattleCutOffRoute=2`）と、本拠地攻撃の枠の歩兵が敵の本拠地に着き、小銃で約10秒で本拠地の耐久が半分になった（STATUS 11-25 16時45分）。守りは「脅威のとき守りの小隊を1個雇う」だけで、出ている小隊の呼び戻しは無い。

## 2. ユーザーの決定（11-25）

| 項目 | 決定 |
|---|---|
| 基地の形 | 本拠地を複数の区画でできた基地にする |
| 基地の耐久 | 小銃の損害を下げる |
| 勝ち方 | 基地の耐久を0にする／基地の中の守備隊を倒す。**どちらでも勝ち（それぞれ独立）** |
| 守備隊 | 基地専属の守備隊を置く。命令できる |
| プレイヤー | プレイヤーも守備隊に指示できる |
| 砲撃 | 本拠地の位置が相手に知られたら、砲撃で攻撃できる |

## 3. 今のコードとの関係

- 小銃の損害：`UBattleLeaderRuntime` の射撃（BattleLeaderRuntime.cpp の `DamageBase` 呼び出し）が1発 10 をそのまま与える。対戦車弾 60、戦車砲 30、迫撃砲 20 は別の値。
- 砲撃の条件：迫撃砲・自走砲・戦車砲は、今も「自分か自軍が敵の本拠地を見た」ときだけ本拠地を撃つ（BattleArtillery.cpp 627〜632行、BattleTankGun.cpp 87〜95行、`bHomeCovered`／`ArtilleryHomeObserved`）。決定の「位置が知られたら砲撃できる」は、今の仕組みをそのまま使える。
- 勝敗：`UBattleMatch::DamageBase` が耐久0で `Finish`。守備隊の全滅での勝ちは無い。
- 守り：`AreaHireNeed`／`CompositionHomeThreat` が脅威のとき目的101の小隊を1個雇う。

## 4. 段階

1. **小銃の損害を下げる** `-BattleBaseRifleDamage=x`（既定0＝今のまま。`movestall` 0eada2f）。固定場面 `Test-Area.ps1 -BaseRifleDamage` と、マップK 2シード（値2と合わせる）。
2. **守備隊と「守備隊の撃破でも勝ち」**（既定0の切替）。今のマップのまま、本拠地の平地に専属の守備隊を置く。AI とプレイヤーのどちらも命令できる。
3. **基地を複数の区画にする**。マップの系統と場所を合わせて設計する（区画の監査、経路、塀の止まり）。

## 5. 段階2の決定（ユーザー、11-25 17時10分ごろ）

| 項目 | 決定 |
|---|---|
| 守備隊の大きさ | 小銃小隊2個 |
| 基地を離れる | 離れられない（命令の行き先は基地の範囲の中だけ） |
| 守備隊での負け | 基地の範囲に生きた守備隊が居なくなり、**相手が一定時間そこを占領したとき** |

作るもの（どれも1つの切替 `-BattleBaseGarrison=1`、既定0 の中）：

1. 開幕に両軍の本拠地へ小銃小隊2個を守備隊として置く（部隊の枠・AI の割り振り・前線の群・補給戻りの対象から外す）。
2. 守備隊への命令は基地の範囲の中に丸める（プレイヤー・AI とも）。AI は基地の中で守る命令を出す。
3. 占領の時計：基地の範囲に生きた守備隊が0で、相手の生きた歩兵が居る間だけ進む。相手が居なくなれば戻る。一定時間で相手の勝ち。
4. 画面：自軍の守備隊の残りと占領の時計、敵の守備隊は最後に見た数。
5. 固定場面：守備隊を倒しただけでは終わらない／占領の時計が満ちると終わる／相手が出ると時計が戻る／守備隊は基地を出ない。

## 6. まだ決まっていないこと（仮の値で作り、あとで変えられるようにする）

- 補充：**仮に「補充なし」**（答えが無かったので仮置き）。
- 基地の範囲：仮に本拠地から半径60m（段階3で区画に置き換える）。
- 占領の時間：仮に30秒。占領に数える相手は歩兵だけ（車両だけでは占領にならない）。
- 守備隊が居る間に相手が基地に入っても時計は進まない。
- AI の本拠地攻撃の枠（今は開幕から10%）を、基地が固くなったあとどう送るか。

## 7. 追加の決定（ユーザー、11-25 17時30分ごろ）

| 項目 | 決定 |
|---|---|
| 購入から出現まで | **常に一定の時間を置く**（基地の件に限らない。何をいつ買うかの戦略性のため） |
| 占領されかけの基地 | 基地の範囲に敵の歩兵が居る間は、購入・補充の出現を止める（上の時間に加えて） |
| 精鋭の本拠地攻撃 | AI は敵の基地が**見つかってから**精鋭小隊を送り、躍進で区画を制圧する |

作るもの（別々の切替、どれも既定0。守備隊の第1版のあと）：

- `-BattleHireDelay=秒`：購入（プレイヤー・AI）から出現までの時間。資源は購入のときに払う。待ちの間は部隊の枠を1つ使う。画面に「到着まで n 秒」。取り消しの扱い（返金）は未定。仮の値は20秒。経済・AI戦略の系統の雇用（`UpdateHireQueue`・購入予約・編成AI）と重なるので、入れる前にその系統の今の形を確かめる。
- `-BattleBaseSpawnBlock=1`：基地の範囲に敵の歩兵が居る間、出現を待たせる（時間は止めずに、居なくなったら出る）。
- `-BattleBaseAssaultElite=1`：本拠地攻撃の枠を精鋭小隊に限り、敵の基地を見たあと（`bHomeCovered`／砲撃と同じ条件）だけ送る。それまでその小隊は普通の割り振り。
